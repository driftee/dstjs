# @driftee/dstjs-core

[简体中文](./README.zh-CN.md)

Platform-neutral data formats and algorithms shared by
[`@driftee/dstjs`](https://www.npmjs.com/package/@driftee/dstjs), browser
players, and future editors.

The package does not depend on Node.js APIs, DOM APIs, Canvas, or native image
processing libraries.

```ts
import {
  createSpriteAnimationTransform,
  type SpriteAnimationDocument,
} from "@driftee/dstjs-core/sprite-animation";
```
